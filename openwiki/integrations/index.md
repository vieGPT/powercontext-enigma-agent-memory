# Files

- [Agent Integration Capability Matrix](capability-matrix.md) - How integrations/capabilities.toml declares which agent hosts and framework adapters support which PowerContext capabilities, how the manifest validators and generators produce the checked-in matrix pages, and how to add or check a host.
- [Claude Code Plugin Integration](claude-code-plugin.md) - How the PowerContext Claude Code marketplace plugin wires SessionStart and UserPromptSubmit hooks, the MCP server, and Scope resolution through POWERCONTEXT_CLAUDE_SCOPE_ID, including the fallback when no Scope ID is configured and how it differs from the Codex plugin.

- [Framework and Platform Adapters](framework-adapters.md) - Maps each PowerContext Python framework adapter (LangChain middleware, LangGraph recall and tools, Pydantic AI capability, OpenDAL Connector) and platform integration (Dify plugin, Cindy hooks, MiniMax native plugin) to its entry module, the public Client or HTTP operation it calls, and its fail-open, scope, and capture behavior.
- [Other Host Adapters (Hermes, OpenClaw, ZCode, OpenCode, Kimi Code, WorkBuddy, Pi, DSH)](host-adapters.md) - Reference for the Hermes, OpenClaw, ZCode, OpenCode, Kimi Code, WorkBuddy, Pi, and DeepSeek Harness (DSH) host adapters. Covers the CLI installer modules, the plugin, hook, and extension files each host ships, native activation, doctor checks, host-specific constraints, and focused tests.
