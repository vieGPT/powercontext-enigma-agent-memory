# Files

- [Server Deployment (Local Service, Docker, Helm, Remote)](deployment.md) - Runbook for deploying the PowerContext Server as a foreground process, a current-user native service (systemd, launchd, Task Scheduler), a Docker image, a Helm chart, or behind remote clients and the gateway over Unix sockets. Covers listener and authentication boundaries, lifecycle commands, and failure modes.
- [Database Migrations, Data Migration and Portable Archives](migrations-and-archives.md) - Runbook for PowerContext Server schema revisions (db-migrate), legacy 1.3.0 and 1.4.0 upgrade admission and rejection, maintenance locks and recovery, Processing and Atomic Memory data migrations, the upgrade release gate, and portable .pcb archive export and restore.
- [Observability, Metrics and Tracing](observability.md) - How PowerContext's Server emits Prometheus metrics, OpenTelemetry request and worker traces and operational logs, how the observability CLI provisions or connects the reference stack, and how the Phoenix and Langfuse trace integrations are configured. Covers the disabled-tracing and missing-endpoint fallbacks.
- [Troubleshooting and Recovery Runbook](troubleshooting.md) - Diagnostic procedure for PowerContext operators. Covers which command reports which state, the ready, degraded and not_ready readiness outcomes, background processing delays, and recovery for Topic Memory and schema migrations.
